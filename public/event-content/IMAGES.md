# Event images

Put the church logo and event photos in this folder. In event.json, set each logoUrl or photo src to a path beginning with /event-content/images/.

For example, if you save the logo here as images/logo.png, set logoUrl to /event-content/images/logo.png. For an event photo, set src to /event-content/images/youth-gathering.jpg and write its alt text.

Leave src as null to keep the labeled photo placeholder.
